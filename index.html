Share this setup with the other coaches

Set the week once here — opponent, date, play sheet, roster. Publish it, and every other device picks all four up the next time it opens with a signal. Nobody else types anything.

  1. Click Download setup.json.
  2. In the GitHub repo: Add file → Upload files → drag setup.json in → Commit.
  3. Other devices see “New setup available” the next time they open online.

No GitHub handy? Send the file by text or AirDrop and have them tap Load a setup file.

Export

Do this on the drive home, before anyone closes the tab.

  • Hudl CSV — one row per filmed play, in order, in Hudl’s columns. This is the file you import to Hudl.
  • Full CSV — everything, including dead-ball penalties, camera-missed snaps, player names and note tags. For your own spreadsheet.
  • Backup — the whole game in one small file. Load it in the Season tab for year-to-date totals, and keep it in case a device dies.

Send opens the phone’s share sheet — AirDrop it to a laptop or mail it to yourself without hunting through Files. Copy puts the whole thing on the clipboard for a paste into Sheets.

Sending it to Hudl
  1. Upload the game film to Hudl and let it split into clips.
  2. Video → Library, pick the game, three-dot menu → Import Data.
  3. Choose the Hudl import CSV. Match each of our column names to a Hudl column from the drop-downs — you only do this carefully once.
  4. Import. The data lands as its own playlist, then match it to the video.
  5. Row 1 is clip 1. If they're off by one, you skipped a snap — find it in the strip at the top of the Log tab.
